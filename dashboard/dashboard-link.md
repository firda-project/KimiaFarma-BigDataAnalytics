# 📊 Kimia Farma Business Performance Dashboard

This directory contains the links and documentation for the interactive executive dashboard built for **PT Kimia Farma Tbk**.

---

## 🔗 Dashboard Access

* **Interactive Looker Studio Dashboard:** [View Dashboard Here](https://lookerstudio.google.com/)
* **Project Presentation Deck:** [View Presentation Deck](https://drive.google.com/file/d/1Feoj8-esZXHgwzB8NKvs3kP6fSJ_mkbW/view?usp=sharing)

---

## 🎯 Key Dashboard Features

1. **Overall Business Performance:** Provide a high-level overview of Kimia Farma's business performance from 2020--2023.
2. **Branch & Product Performance:** Analyze transaction and sales contribution across provinces, cities, branches, and products.
3. **Geographic & Customer Analysis:** Analyze profitability across regions and evaluate customer experience through ratings.
